## 1. P5-A — six reported risks

Each risk was reproduced as a test before the fix, or verified red against the
0.3.4 code. The two guard tests were observed failing before the change
(12/15 passing); the Python fixes landed with their negative tests.

| Risk | 0.3.4 source | Verdict | Fix | Test |
| --- | --- | --- | --- | --- |
| 1. The same `session_id` can delete a live lock | `acquire_lock` removed the lock when `data["session"] == session` | **CONFIRMED** | OS byte lock (`msvcrt`/`flock`), no same-session bypass, no deletion | `work_state` "a live lease blocks a real process even with the same session" |
| 2. A TTL can be stolen and the old owner deletes the new lock | `age > ttl` branch plus unconditional `os.remove` in `release_lock` | **CONFIRMED** | no TTL; the OS releases on process death; `release_lock` checks the acquisition token | `work_state` "an ancient timestamp on disk does not let another process steal a live lease" |
| 3. Empty `permission.resources` is allowed | the loop did not run and returned `allow: true` | **CONFIRMED (red)** | empty shell resources → `allow: false` | guard "a shell permission with no command is denied" |
| 4. Only root-level control-plane paths are protected | `PROTECTED` was matched against the workspace-relative path | **CONFIRMED** | `_eos_paths.is_control_plane` matches `.agents/evidence`, `.agents/state`, `.opencode/plugin`, `.eos` at any depth | `write_gate` "a nested project's control plane is refused"; `auto_decision` nested scope |
| 5. `update_files` is an unlocked read-modify-write | no lock around the map | **CONFIRMED** | the same OS lock serialises `update_files` and `mark_dirty` | `project_map` "a held map lock serialises a second writer"; "two real writers do not lose each other's update" |
| 6. The post-write queue matches by session + path | LIFO match, no call id | **CONFIRMED (red)** | `note/take` carry the host call id; no id → oldest-first, one completion per entry | guard "the post-write queue pairs a tool call id exactly once"; "a call id is never matched across sessions" |

`BLOCKED: unknown project` in impact. Found by the math and cross-process

## 2. P5-B — mechanical benchmark

`engine/tools/p5_benchmark.py` creates real fixture projects, runs the real EOS
tools in-process, and judges each scenario against a declared invariant. No
model is called. The artifact is written to `.agents/evidence/p5/`.
