# GPT-6.2 Astra public guidance

EOS applies [the shared activation discipline](../core/activation-discipline.md) for each provider. `fable-5-1` remains the skill identifier for existing routing, installation and evidence references. Its companion `fable5-thinking` remains available on existing routes.

The current GPT-6.2 guidance informs explicit outcome criteria, reversible assumptions, end-to-end ownership and regression evidence. The reasoning and tools guides also inform concise context, native tool contracts, batching independent calls and retaining durable work state across host or model changes. Provider capabilities require evidence from the actual host. A context supplied to one host is not evidence that the agent used a skill, delegated a task or passed a gate.
